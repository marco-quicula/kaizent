# Veterinarians

Click **Veterinarians** in the menu to see the clinic's veterinarians and their
specialties (radiology, surgery or dentistry; a veterinarian can have none or several).
The list shows 5 veterinarians per page.

The same list is available as JSON at `/vets`, for integrations.

Veterinarians and specialties are reference data: there is no screen to add or edit them.
An administrator changes them in the database, like pet types (see [pets.md](pets.md)).
Visits are not assigned to a veterinarian.
